거북선 컷 작업대
================

설치 방법
---------
1. 이 폴더를 압축 해제합니다. (압축 안에서 바로 실행하면 안 됩니다)
2. INSTALL.bat 을 더블클릭합니다.
3. 바탕화면에 [거북선 작업대] 아이콘이 생깁니다.

설치되는 위치
-------------
  바탕화면\거북선 작업대\작업대.html
  바탕화면\거북선 작업대.lnk        (바로가기)

Chrome 이나 Edge 가 있으면 앱 모드로 열립니다. 주소창과 탭이 없는
단독 창이라 브라우저가 아니라 프로그램처럼 보입니다.


쓰는 법
-------
[다음 작업] 카드에 아직 만들지 않은 것 중 가장 앞의 한 장이 뜹니다.

  프롬프트 복사  ->  생성  ->  카드에 적힌 이름으로 저장
  ->  [복사하고 완료 표시]  ->  자동으로 다음 장

저장 위치는 E:\YouTube\국뽕\1.이순신 입니다.


꼭 지킬 것
----------
k1  =  새 생성으로 시작        (카드에 붉은 배지, 목록에서 붉은 선)
k2~ =  그 스레드에서 편집

비트(B1/B2/B3...)가 바뀌면 다시 새 생성으로 돌아갑니다. 장소가 다릅니다.
이 구분을 놓쳐서 11장을 통째로 다시 만든 적이 있습니다.

16:9, 1장 생성.


시드
----
1블-b1-k1 을 먼저 한 장 뽑고, 마음에 드는 결과의 시드 값을 위쪽
[시드] 칸에 넣습니다. 이후 183장의 [SEED] 가 전부 자동으로 바뀝니다.
183장의 그림체를 하나로 묶는 유일한 장치입니다.


진행 상황
---------
체크 표시는 이 브라우저에만 저장됩니다.
다른 PC 로 옮기려면 [진행 내보내기] 로 받은 JSON 을 그쪽에서
[가져오기] 하면 됩니다.

브라우저 데이터를 지우면 체크도 함께 지워지니, 가끔 내보내
두시는 편이 안전합니다.


지우려면
--------
바탕화면의 [거북선 작업대] 폴더와 [거북선 작업대] 바로가기를
삭제하면 끝입니다. 레지스트리나 다른 위치는 건드리지 않습니다.
