# 보고서 자동 작성기

올려주신 두 파일을 분석했고, 그 결과로 만든 도구입니다.

- **엑셀 데이터 → 표준 서식 보고서**: 파일을 끌어다 놓으면 한글에서 열리는 보고서가 나옵니다
- **메모장 초안 → 표준 서식 보고서**: `□ ○ - ※` 기호만 맞춰 적으면 글꼴·크기·줄간격·여백이 자동으로 맞춰집니다

그래서 이 뼈대 하나만 자동으로 만들면 모든 유형에 쓸 수 있습니다.

**⚠ 매크로는 이 데이터에서 돌아가지 않습니다.**
「dashboard」 버튼에 연결된 `BuildSalesDashboard` 매크로는 **다른 데이터(판매 실적)용**입니다.

**열 이름으로 데이터를 직접 읽습니다.** 그래서 열 순서가 바뀌거나 행이 늘어나도 그대로 동작합니다.

## 2. 무엇을 자동화했나

```
 ┌──────────────┐     ┌──────────────┐     ┌──────────────────┐
 │ 엑셀 (.xlsm) │ ──▶ │ 초안 (.txt)  │ ──▶ │ 보고서 (.docx)   │ ──▶ 한글에서 열어 .hwp 저장
 └──────────────┘     └──────────────┘     └──────────────────┘
   분기 집계·비교       사람이 고칠 수 있음    표준 서식 자동 적용
```

중간에 **메모장 초안**을 두었습니다. 숫자는 자동으로 뽑되, 문장은 사람이 다듬을 수 있어야 하기 때문입니다.
초안을 고친 뒤 다시 끌어다 놓으면 보고서가 새로 만들어집니다.

### 엑셀에서 자동으로 뽑는 내용 (분기 상담 실적 현황 보고)

| □ 큰제목 | 내용 |
| --- | --- |
| 실적 개요 | 상담·전환·매출을 **전 분기와 비교**(▲▼), 월별 표 |
| 유입경로별 전환 현황 | 전환율 최고·최저 경로와 그 차이, 경로별 표 |
| 상담원별 실적 | 매출 상위 5명 표, 상위 5명의 매출 비중 |
| 지역·상품별 매출 | 지역 순위, 상품 상위 3개 |
| 향후 조치 | **후속 연락 대기 중 관심 고객 수** → 우선 연락 대상 |

영어 값(`Google Ads`, `West Coast` 등)은 한국어로 바꿔 씁니다 (`leads.py`의 `KO`).

## 3. 쓰는 법

### 윈도우 — 끌어다 놓기 (권장)

1. [python.org](https://www.python.org)에서 파이썬을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. `report_auto\보고서만들기.bat` 위에 파일을 **끌어다 놓습니다**.
   - 엑셀(.xlsx/.xlsm)을 놓으면 → 가장 최근 분기의 실적 보고서가 나옵니다 (`.docx` + `.txt` 초안)
   - 초안(.txt)을 놓으면 → 표준 서식 보고서가 나옵니다
3. 결과 파일은 원본 옆에 생깁니다. 한글에서 열고 **다른 이름으로 저장 → .hwp** 하면 됩니다.

처음 한 번은 필요한 부품(python-docx, openpyxl)을 자동으로 설치합니다.

### 명령어

```bash
pip install -r report_auto/requirements.txt

# 엑셀 → 실적 보고서 (분기를 생략하면 가장 최근 분기)
python -m report_auto 엑셀 고객데이터.xlsm --분기 2026-Q2 --부서 공대통합행정실

# 초안 → 보고서
python -m report_auto 작성 report_auto/examples/예시_교육부방문계획.txt
```

### 초안 쓰는 법

```
제목: 총장님, 교육부 방문 계획(안)
날짜: '24. 6. 14.(금)
부서: 총무과
개요: (적으면 제목 아래 개요 상자가 생깁니다. 없으면 생략)

□ 방문 개요
○ (목적) 중앙부처와의 **소통 강화** 및 건의사항 전달
- 세부 내용
· 더 세부
※ 참고 (중고딕으로 작게)
| 시간 | 주요 내용 | 비고 |
| 06:40~10:15 | 학교 출발 | |
붙임: 현장 사진 1부.
```

- `**굵게**` — 굵은 글씨. `○ (목적)`처럼 맨 앞 괄호 제목은 자동으로 굵게 합니다
- `I.` `II.` — 4~5쪽 이상 긴 보고서의 큰 항목
- `|`로 시작하는 줄 — 표. 첫 줄이 머리행(회색)이 됩니다
- `#`로 시작하는 줄 — 메모. 보고서에 찍히지 않습니다
- `o` `ㅇ` `•`처럼 흔히 잘못 치는 기호도 `○` `·`로 바꿔 줍니다

예시: `examples/예시_교육부방문계획.txt` (참고 자료 5쪽을 그대로 옮긴 것)

## 4. 알아둘 점

- **글꼴**: HY헤드라인M·휴먼명조·HY중고딕은 한글 프로그램을 설치하면 함께 깔립니다. 없는 PC에서는 비슷한 글꼴로 대신 보입니다.
- **줄간격 160%**: 한글의 160%는 글자 크기의 1.6배입니다. 워드의 '배수 1.6'은 이보다 훨씬 넓습니다. 그래서 '고정 간격(글자 크기 × 1.6)'으로 넣어 한글에서 보던 모양과 맞췄습니다.
- **금액 단위**: 엑셀에 통화가 적혀 있지 않아 '천' 단위 숫자로만 표시합니다.
